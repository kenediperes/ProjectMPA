# ERP System – Frontend

A modern, responsive single-page application (SPA) for enterprise resource planning, built with **React 18**, **React Router v6**, **Axios**, and a custom design system with light/dark theme support.

## 📦 Modules Covered

- **Dashboard** – overview with key metrics, stock alerts, recent activities.
- **CRM & Sales** – manage customers, sales quotations, sales orders.
- **Purchasing** – manage suppliers, purchase orders, supplier approval.
- **Service** – service orders and task assignments.
- **Production** – work orders, assembly, and manufacturing.
- **Quality Control** – QC checks, pass/fail/rework tracking.
- **Inventory** – stock checks, stock-in/out, alerts.
- **Invoicing** – generate invoices, payment confirmation, overdue reminders.
- **Reporting** – sales, inventory, financial, and notification (WhatsApp/Telegram/Email) reports.
- **Settings** – theme, notification preferences, language.
