# ERP System - Enterprise Resource Planning

Sistem ERP terintegrasi berbasis web yang mencakup manajemen penjualan, pembelian, inventaris, layanan, produksi, kontrol kualitas, dan pelaporan keuangan. Dibangun dengan **ReactJS** untuk frontend dan **PostgreSQL** untuk backend.

## Fitur Utama

- **Dashboard** – Gambaran kinerja bisnis secara real-time.
- **Manajemen Inventaris** – Melacak stok barang, peringatan stok rendah, dan mutasi barang.
- **Penjualan** – Buat kutipan penjualan, pesanan penjualan, dan pantau status pengiriman.
- **Pembelian** – Kelola pesanan pembelian dengan persetujuan pemasok.
- **Layanan** – Permintaan layanan dan penugasan tugas.
- **Produksi** – Pesanan kerja, perakitan, dan proses produksi.
- **Kontrol Kualitas** – Inspeksi hasil produksi dengan status lulus/gagal dan proses ulang.
- **Penagihan** – Buat faktur, konfirmasi pembayaran, dan kirim pengingat otomatis.
- **Laporan** – Laporan penjualan, inventaris, keuangan, dan laporan WhatsApp/Telegram/Email.
- **Notifikasi** – Pengingat otomatis melalui notifikasi internal.

## Teknologi yang Digunakan

### Backend
- Node.js + Express
- PostgreSQL
- JWT untuk autentikasi
- Bcrypt untuk hashing password

### Frontend
- ReactJS
- Material-UI untuk komponen UI
- React Router untuk navigasi
- Axios untuk HTTP client
- Recharts untuk grafik laporan

### DevOps
- Docker & Docker Compose
- Nginx (opsional untuk production)
