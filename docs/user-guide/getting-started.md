# Getting Started - User Guide

## Welcome to ERP System

This guide will help you navigate the system and perform basic tasks.

---

## System Requirements

- Modern web browser (Chrome, Firefox, Edge)
- Internet connection
- Valid user account (provided by administrator)

---

## First Login

1. Open the ERP system URL (provided by your admin).
2. Enter your **username** and **password**.
3. Click **Login**.
4. You will be redirected to the **Dashboard**.

> Default admin credentials: `admin` / `admin123` (change immediately after first login).

---

## Dashboard Overview

The dashboard provides a snapshot of key metrics:

- **Sales Orders** – Total orders and revenue.
- **Purchase Orders** – Total purchases and spending.
- **Inventory** – Total products and items in stock.
- **Unpaid Invoices** – Number and amount of outstanding invoices.
- **Pending Services** – Service requests waiting for action.

You can click on any card to navigate to the relevant section.

---

## Navigation Menu

The sidebar menu contains all modules:

| Menu Item | Description |
|-----------|-------------|
| Dashboard | Home page with summary |
| Products | Manage inventory items |
| Sales Orders | View and create customer orders |
| Purchase Orders | Manage supplier orders |
| Service Orders | Handle service requests |
| Invoices | Billing and payment tracking |
| Reports | Generate business reports |

---

## User Profile & Logout

- Click the avatar icon in the top-right corner to access your profile and logout.

---

## Notifications

- The bell icon shows unread notifications.
- Click to view reminders, payment confirmations, and system alerts.

---

## Keyboard Shortcuts

- `Ctrl + S` – Save current form
- `Esc` – Close dialog/modal
- `Ctrl + /` – Open help

---

## Getting Help

- Check the documentation in `/docs` folder.
- Contact your system administrator for support.
